# 코드설명 답변 템플릿 (범용)

적용범위:
- 코드 설명 답변에 이 템플릿 적용이 필요할 때만 사용
- 평소에는 자동 적용하지 않음
- 답변 품질 보정이 필요할 때 Add Context로 수동 적용

규칙:
- 정중한 일반 문체 사용
- 코드블록 내 흐름 주석은 // 1), // 2) 형식 사용
- 주석은 코드 오른쪽이 아니라 코드 줄 위에 작성
- 코드 여러 개를 설명할 때는 코드블록 앞에 전체 흐름도를 한 번 작성한다
- 각 코드블록의 설명에는 "이 코드가 전체 흐름의 어느 단계를 담당하는지"를 포함한다
- 코드블록마다 아래 2줄을 반드시 포함

코드위치: (파일명 또는 함수명)
설명: (이 코드가 무엇을 하는지 + 전체 흐름에서 어느 단계를 담당하는지, 초보자도 이해할 수 있도록)
